# Flexible Manipulation

Mobile robot manipulation with Isaac Sim 5.1, ROS 2 Humble, and MoveIt 2.

## Current Development
- Cartesian end-effector control using MoveIt IK
- Arm trajectory execution through ROS 2
- Gripper open/close control
- Pick and lift sequence

## Planned
- Flexible manipulation under positioning errors
- Navigation and manipulation integration
- Perception-based target updates
